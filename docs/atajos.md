# Descargador de YouTube - Atajos de Teclado y Accesibilidad

Guía rápida de referencia con todos los atajos de teclado y combinaciones de teclas disponibles en el **Descargador de YouTube**.

---

## 1. Atajos Globales y Acciones Principales

| Combinación de Teclas | Acción |
| :--- | :--- |
| **`Ctrl + F`** | Llevar el foco al campo de búsqueda de texto o URL |
| **`Ctrl + Shift + N`** o **`F3`** | Cargar los siguientes resultados de la búsqueda actual (paginación continua) |
| **`Ctrl + P`** | Ver o reproducir los vídeos seleccionados / marcados |
| **`Ctrl + L`** | Reproducir toda la lista completa en modo continuo |
| **`Ctrl + Q`** | Añadir los vídeos seleccionados a la cola de reproducción secuencial |
| **`Ctrl + Shift + Q`** | Reproducir la cola de reproducción secuencial acumulada |
| **`Ctrl + J`** | Abrir y gestionar la cola de reproducción (solo visible cuando hay contenido) |
| **`Q`** | (En el reproductor) Abrir y gestionar la cola de pistas en reproducción continua |
| **`Ctrl + Flecha Derecha`** o **`N`** | (En el reproductor) Avanzar a la siguiente canción de la lista |
| **`Ctrl + Flecha Izquierda`** o **`Ctrl + P`** | (En el reproductor) Retroceder a la canción anterior de la lista |
| **`P`** | (En el reproductor) Pausar o reanudar la reproducción |
| **`S`** | (En el reproductor) Detener la reproducción |
| **`A`** | (En el reproductor) Activar o desactivar modo aleatorio (Shuffle) |
| **`Espacio`** | (En el reproductor) Accionar o pulsar el botón enfocado |
| **`Flecha Arriba / Abajo`** | (En el reproductor) Subir o bajar volumen (+/- 5%) |
| **`M`** | (En el reproductor) Silenciar o reactivar sonido (Mute) |
| **`Ctrl + D`** | Iniciar la descarga de los elementos seleccionados (o de todos los vídeos de un canal o playlist) |
| **`Ctrl + Shift + D`** | Descargar todos los vídeos de la lista, canal o lista de favoritos actual |
| **`Ctrl + O`** | Abrir la carpeta de descargas en el Explorador de Windows |
| **`Ctrl + H`** | Ver y cargar la lista de favoritos guardados |
| **`Ctrl + Shift + H`** | Cargar el Historial de reproducciones de YouTube |
| **`Ctrl + Shift + W`** | Cargar la lista "Ver más tarde" de YouTube |
| **`Ctrl + Shift + Y`** | Cargar las listas de reproducción de la cuenta de YouTube |
| **`Ctrl + Shift + P`** | Reproducir de forma continua la lista de favoritos |
| **`Ctrl + B`** | Añadir o eliminar el elemento actual de favoritos |
| **`Ctrl + M`** | Cambiar o mover los elementos seleccionados (o el del cursor) a otra lista de favoritos |
| **`Supr`** | Eliminar el elemento seleccionado de favoritos (con confirmación según preferencias) |
| **`Ctrl + C`** | Copiar el enlace del elemento seleccionado al portapapeles |
| **`Ctrl + U`** | Comprobar y actualizar yt-dlp a la versión Nightly |
| **`Ctrl + Shift + U`** | Comprobar actualizaciones de la aplicación en buscaapps.com |
| **`Ctrl + ,`** o **`F2`** | Abrir la ventana de Preferencias y Opciones |
| **`F1`** | Abrir el Manual de Usuario completo en el navegador |
| **`Escape`** | Retroceder nivel a nivel en la navegación jerárquica (vídeos -> lista -> canal -> favoritos/búsqueda) o limpiar resultados (y cerrar diálogos) |
| **`Alt + Flecha Izquierda`** | Retroceder al nivel de navegación previo en la lista de resultados |
| **`Alt + F4`** | Salir de la aplicación |

## 2. Atajos Mnemónicos de Acceso Rápido (`Alt + Letra`)

| Combinación | Control Enfocado / Acción |
| :--- | :--- |
| **`Alt + T`** | Campo de texto de búsqueda (*Términos o URL*) |
| **`Alt + I`** | Selector de *Tipo* de búsqueda (Vídeos, Canales, Listas) |
| **`Alt + B`** | Botón *Buscar* |
| **`Alt + S`** | Botón *Siguientes resultados* (carga la siguiente página) |
| **`Alt + L`** | *Lista de resultados* encontrados |
| **`Alt + F`** | Selector de *Formato* de descarga (MP4, MP3, M4A, FLAC, WAV) |
| **`Alt + C`** | Campo de ruta de la *Carpeta de descarga* |
| **`Alt + E`** | Botón *Examinar...* carpeta de descargas |
| **`Alt + D`** | Botón *Descargar selección* |
| **`Alt + P`** | Botón *Reproducir selección* |
| **`Alt + X`** | Botón *Cancelar* descarga activa |

## 3. Navegación e Interacción en la Lista de Resultados

| Tecla | Acción |
| :--- | :--- |
| **`Flechas Arriba / Abajo`** | Navegar entre los elementos (filas) de la lista |
| **`Flechas Izquierda / Derecha`** | Navegar y anunciar las columnas (Título, Canal, Duración, Visitas) de la fila actual con el lector de pantalla |
| **`Espacio`** | Marcar o desmarcar la casilla del elemento enfocado (puedes marcar pistas salteadas como la 1ª, 3ª, 6ª y 10ª para reproducirlas en secuencia continua con **`Ctrl + P`**) |
| **`Ctrl + A`** | Seleccionar y marcar todos los elementos de la lista |
| **`Enter`** | En un canal o playlist: listar sus vídeos. En un vídeo: reproducir / abrir reproductor |
| **`Doble Clic`** | En un canal o playlist: explorar contenidos. En un vídeo: reproducir / abrir reproductor |
| **`Menú Contextual`** *(Tecla Aplicaciones / Clic Derecho)* | Opciones avanzadas: cambiar de lista de favoritos (submenú con todas las listas, crear nueva lista o diálogo), reproducir, descargar, favoritos, mostrar vídeos del canal al que pertenece, copiar URL del canal, etc. |

## 4. Controles Dentro del Reproductor Multimedia (VLC)

| Tecla | Acción |
| :--- | :--- |
| **`P`** | Pausar o reanudar la reproducción |
| **`S`** | Detener la reproducción |
| **`A`** | Alternar modo aleatorio (activar / desactivar Shuffle) |
| **`Espacio`** | Pulsar / accionar el botón enfocado en la ventana del reproductor |
| **`Flecha Arriba`** | Subir volumen (+5%) |
| **`Flecha Abajo`** | Bajar volumen (-5%) |
| **`M`** | Silenciar o reactivar sonido (Mute) |
| **`Ctrl + Flecha Derecha`** o **`N`** | Avanzar a la siguiente canción / pista de la lista en reproducción |
| **`Ctrl + Flecha Izquierda`** | Retroceder a la canción / pista anterior de la lista en reproducción |
| **`Ctrl + Shift + C`** o **`Ctrl + C`** | Copiar el enlace directo del vídeo en reproducción al portapapeles |
| **`B`** o **`F`** | Añadir o eliminar pista actual de Favoritos |
| **`Supr`** | Eliminar la pista en reproducción de Favoritos (con confirmación configurable) |
| **`R`** | Alternar repetición continua (activar / desactivar bucle) |
| **`F11`** | Activar o desactivar la ventana de vídeo (alternar modo vídeo y modo solo audio) |
| **`F9`** | Anunciar al lector de pantalla el tiempo transcurrido |
| **`F10`** | Anunciar al lector de pantalla el tiempo restante |
| **`Ctrl + D`** | Descargar el vídeo que se está reproduciendo en ese momento |
| **`Escape`** | Cerrar el reproductor y volver a la ventana principal |
| **`Flecha Derecha`** | Avanzar 10 segundos en la reproducción |
| **`Flecha Izquierda`** | Retroceder 10 segundos en la reproducción |
| **`Shift + Flecha Derecha`** | Avanzar 1 segundo en la reproducción |
| **`Shift + Flecha Izquierda`** | Retroceder 1 segundo en la reproducción |
| **`Shift + Alt + Flecha Derecha`** | Avanzar 5 segundos en la reproducción |
| **`Shift + Alt + Flecha Izquierda`** | Retroceder 5 segundos en la reproducción |
| **`Ctrl + Shift + Flecha Derecha`** | Avanzar 1 minuto en la reproducción |
| **`Ctrl + Shift + Flecha Izquierda`** | Retroceder 1 minuto en la reproducción |
| **`Ctrl + Alt + Shift + Flecha Derecha`** | Avanzar 5 minutos en la reproducción |
| **`Ctrl + Alt + Shift + Flecha Izquierda`** | Retroceder 5 minutos en la reproducción |

> **Nota sobre el uso de las flechas en el reproductor**:
> - **`Ctrl + Flecha Derecha / Izquierda`** (o tecla **`N`** para siguiente): Cambian de **canción completa** en la lista en reproducción.
> - **`Flechas Izquierda / Derecha`** (solas o con **`Shift`** / **`Alt`**): Desplazan la posición de reproducción en segundos o minutos **dentro de la misma canción** (10s, 1s, 5s, 1m, 5m).
